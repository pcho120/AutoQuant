To install all required packages
    python -m pip install -r requirements.txt

Install supabase
    Inside env
        python -m pip install supabase
        or
        pip install supabase

Local environment variables
    secrets.env must use KEY="value" lines with no heading text.
    Required: SUPABASE_URL, SUPABASE_KEY, NEWS_API_KEY

To run on terminal\n
    cd <path>
    python -m install virtual environment
    .\env\Scripts\activate

Create a virtual environment
    python -m venv <environment name>
    .\env\Scripts\activate
    .\env\Scripts\Activate.ps1  

On VScode
    Terminal 1: FastAPI Backend
        cd D:\Dev\AutoQuant
        .\env\Scripts\Activate.ps1
        python -m uvicorn api:app --host 127.0.0.1 --port 8000
    
    Terminal 2: React Frontend
        cd D:\Dev\AutoQuant\frontend
        npm install
        npm run dev -- --host 127.0.0.1 --port 5173

    The backend and frontend do not start data collection automatically.
    The Leverage Engine uses the same two servers and needs no separate process.
    Open the Leverage Engine tab, review the current signal, then run a backtest.

Run data collection jobs independently
    cd D:\Dev\AutoQuant
    # Run in this order to refresh stored data and cached predictions.
    .\env\Scripts\python.exe -m jobs.runner collect_market_data
    .\env\Scripts\python.exe -m jobs.runner collect_news
    .\env\Scripts\python.exe -m jobs.runner analyze_unprocessed_news
    .\env\Scripts\python.exe -m jobs.runner build_prediction_features
    .\env\Scripts\python.exe -m jobs.runner run_model_evaluation
    .\env\Scripts\python.exe -m jobs.runner run_predictions

Production scheduling
    Configure GitHub repository secrets SUPABASE_URL, SUPABASE_KEY, NEWS_API_KEY.
    Optionally configure repository variable COLLECTION_TICKERS.
    Apply db/create_tables.sql before running any new prediction job.
    Enable .github/workflows/data-collection.yml for news every 8 hours (48 requests/day for 16 tickers).
    Enable .github/workflows/market-predictions.yml for DST-safe daily close updates.
    Enable .github/workflows/model-evaluation.yml for weekly retraining/backtesting.

Production frontend/backend
    Set FastAPI CORS_ORIGINS to the deployed React origin.
    Set React build variable VITE_API_BASE_URL to the deployed FastAPI URL.
